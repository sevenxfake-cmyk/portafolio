[Ver portafolio en Vercel](https://portafolio-ten-beta-76.vercel.app/)

## Formación documentada

La sección **Formación** utiliza los 13 PDF originales en `public/certificados/`, correspondientes a 12 cursos y talleres distintos. Los documentos incluyen formación de **Cisco Networking Academy, Oracle Academy y Red Hat**. Se distingue un curso completado de una certificación profesional de examen y una constancia de asistencia.

## Estructura

- `src/App.jsx`: diseño de las secciones y contenido.
- `src/App.css`: estilo general y versiones adaptativas.
- `src/index.css`: reset y estilos globales.
- `src/data/certificados.js`: datos de los documentos.
- `src/assets/rostrodar.png`: fotografía personal.
- `public/certificados/`: certificados y vistas previas.

El rediseño sustituye la interfaz anterior de la guía de laboratorio sin borrar los documentos originales ni los componentes archivados en el proyecto.

## Desarrollo local

Se requiere Node.js y npm.

```bash
npm install
npm run dev
```

Para compilar la versión de producción:

```bash
npm run build
```

## Tecnologías del portafolio

React, Vite, JavaScript, HTML, CSS y Bootstrap. La interfaz utiliza CSS adaptable sin dependencia adicional de una biblioteca de componentes.
